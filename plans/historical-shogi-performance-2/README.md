目標: Native初期局面で天竺大80万NPS、大局60万NPS。実測に基づき採否を決める。

各段階を別測定・別コミット。各ルール4ケースの倍率の幾何平均で10%以上を採用目安とし、
他方・初期・非対象の5%以上低下は再計測し、再現すれば解消または適用を狭める。
葉まで適用・復元し、並列化・末端一括カウント・perft用TTは使用しない。
既存の全生成・コピー・効果の参照実装と比較する。4hop/pending、居喰い、一括捕獲、
有限ジャンプ、禁止条件、在場順・凍結・焼却・王集合・履歴と取り消しを検証する。
バッチは再帰呼出し内だけに保持し、公開手・TTには内部ヒントを含めない。
通常5秒・1msの合法完了手、初期化5秒・線形メモリ64MiB、Chrome82件、
core/AI/app/型/lintを最終確認する。効果のない試作も結果と理由を残す。

ディスク空きは実施開始時104GiBあり、キャッシュ削除は不要。学習関連の既存変更は保持する。

初期perft(3)の実測葉数は天竺大3,119,657、大局28,492,037。外挿より多く、以後この葉数を固定する。
第1段階の初期NPSは天竺大561,006、大局492,823。全8ケース幅5%以内。

第2a段階: 4語以下は従来の値更新を維持。全幅での直接更新試作は天竺大の途中局面が約6%低下し不採用。
21語の大局ではset_cell内の168バイトmemcpyを削減した（逆アセンブルも保存）。

王数キャッシュは大局だけに限定。天竺大への適用は初期NPSが約6%低下し不採用。王でない駒のカウンター書込みも省いた。
