# 第1段階: 王マスへの攻撃判定

状態: 採用済み（2026-11-08）。対象: 和将棋・平安大将棋。比較対象: 大将棋・禽将棋・既存の本将棋。

## 現行と変更範囲

`haitaka/src/extended/classical.rs::classical_acceptable`で候補を仮適用し、
`extended.rs::attacked`が相手駒の全移動先Vecを生成して王に当たるか調べる。
CHECK=trueの和・平安大が主対象。CHECK=falseの大将棋の合法性を変更しない。

1. 現行attackedをテスト用の独立オラクルとして残す。
2. 王相当のマスを列挙し、各相手駒についてそのマスに届くかだけを調べる関数を実装する。
   最初は駒の歩み・走り・方向・ray_limit・遮蔽物に沿う直接判定とし、全移動先Vecを作らない。
3. 固定の歩みは王から逆算できる形へ整理する。汎用の全駒×全マス対の巨大表は作らない。
4. 旧判定との一致後、classical_acceptableの王手検査だけを差し替える。
   最初の変更では盤面コピー・成り・二歩・打ち歩詰め・千日手を同時に変更しない。
5. 攻撃判定の結果とperftの両方を再計時する。

## 正しさ

旧attackedと新判定を固定seedの合法局面で先後とも比較する。
全駒の歩み/走り/有限距離、味方遮蔽・敵遮蔽・王の手前と奥・盤端、
捕獲で開く利き、ピン、王の移動、成り後の利き、王不在/複数王が呼出元で許される場合を覆う。
直接攻撃判定に「攻撃側が実際にその手を合法に指せるか」の再検証を混ぜず、旧関数の意味を維持する。
和・平安大の参照全合法手・全遷移・結果を照合する。禽将棋の打ち歩詰めへ共通関数の変更が及ぶ場合は
専用局面と全参照比較を追加する。大将棋の王手放置許容は維持する。

## 性能と出口

王手検査部分5〜10倍、全体で和2.8〜3.6倍・平安大2.5〜3.1倍は試算。
まず全体+10%以上を採用目標にし、目標に届かなくても結果と原因を記録して判断する。
第1段階はNative/WASMの一致・対応する参照比較・前後NPSが揃ってからコミットし、第2段階へ進む。


## 実装・検証結果

実装コミット: 99998d8e7273b87ddf4e403d9435b05ccf397715。
合法性検査の呼出元だけをルールID 50/15に限定して差し替えた。
王相当のマスと敵駒を列挙し、王との相対座標を駒の歩み・走りへ直接照合する。
歩みの照合は先後方向を逆算した相対座標で行い、追加の逆引き表は使わない。
走りは距離制限と途中の遮蔽物だけを検査する。旧attackedと他の呼出元は維持した。

全駒・両色・全始点/終点、遮蔽物・有限走り、固定seed対局と候補手、
ピン・複数王・王不在・開き王手・王移動のテストを追加した。
workspaceテスト、和・平安大それぞれのextendedテスト31件が成功。
将棋ったー参照実装と変更前Nativeに対し計416局面・14,586遷移の差分は0。
同じ入力の実WASMでも合法手・遷移・結果・履歴再生・公開ハッシュが一致した。

CPU 7固定、Release、同一深さ・葉数、3秒以上×3回の中央値。
NPSは着手を葉まで適用するperftの葉ノード/秒。

初期の5〜10倍という局所仮定より小さく、perft全体も試算を下回ったが、
採用目標の+10%以上を十分に満たした。単体計時の局面分布はperft候補局面と異なるため、
単体倍率から全体の時間配分を厳密に逆算しない。
