# 第4段階: 盤面コピー・一時領域

状態: 4Aコピー省略を採用済み。4B scratch、4C Deltaを別に評価する。第3段階を評価済みの状態で再計時してから対象を決める。

現行のclassical_acceptableは候補ごとに盤面をcloneして仮適用し、pushもcloneする。
大型バックエンドは着手のDeltaを使うが、移動先Vec・小さなDeltaのVec等を繰り返し確保する。

1. 第1〜3段階後の割合と、実際の確保回数/バイトを測る。
2. classicalの候補検証用にscratch盤面を1つ持ち、変更マス・手番・持ち駒・先獅子を差分で戻す。
   まず候補検証だけを変え、履歴全体の表現変更とは分ける。
3. 必要なら実着手の履歴コピーも差分形式へ変更する。反復判定に必要な履歴情報を失わない。
4. 大型の小さなDeltaや候補領域を再利用する。最大数を証明できない除去駒には可変長の退避を残す。
   type100の一括捕獲、火鬼による多数除去を固定長2〜4マスへ切り詰めない。
5. Vecの確保削減とソート/重複除去の変更は別に測る。ソートを除く場合も合法手の一意性と順序の契約を保つ。

大将棋で全体1.15〜1.35倍、和・平安大では第1段階前の割合で1.02〜1.08倍が暫定目標。
変更前のコピー実装をテスト用比較に残し、push/popごとの全盤・持ち駒・状態・キー・履歴を照合する。
無効な候補・中断・早期returnの後もscratchを確実に戻す。
不変の1手生成Vecを保持したまま次の生成を呼ぶ場合や、再帰探索で領域を共有する場合の破壊を検証する。
計時で小さい領域なら最適化しない判断も記録する。

## 第3A後に具体化した候補

第3Aでは手番元のactor候補を共有して天竺大が2.02倍になった一方、
perft(2)の確保回数は259,075→276,566回へ増えた。第3B後の確保回数で改めて評価する。

- 大将棋はCHECK=falseなので、成り後の同一筋枚数だけを元盤の駒数差で判定できる候補では
  検証用の盤面コピーを省ける。味方駒は移動駒以外に消えないことを前提に、元マスの控除と
  最終マスへの追加を行う。二歩が既にある入力・成り・居喰い・戻りを旧コピー処理と照合する。
- 和・平安大・禽将棋は王手検査や打ち歩詰めが必要なので、この省略を適用しない。
  汎用scratchの費用対効果が小さければ履歴形式を複雑にせず、見送る理由を残す。
- 大型Deltaの変更マスは少数をinlineに持ち、超過分だけ可変長Vecへ退避する案を測る。
  一括捕獲・焼却で多数マスが消える場合も全変更を保持する。固定長への切り詰めは行わない。
- コピー省略とDelta領域は別々に測り、採用・不採用を分けて記録する。ソートは変更しない。
